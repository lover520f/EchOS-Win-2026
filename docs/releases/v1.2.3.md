# EchOS-Win v1.2.3

**稳定性与网络环境适配热修。** 集中修复 v1.2.2 使用中反馈的问题，网络受限环境下的连接更可靠。

**修复**

- 修复：启用 TUN 模式（管理员确认重启）后，代理未自动恢复、且偶发停留在空白授权页的问题
- 修复：托盘菜单文字偶尔丢失、点击偶尔无效的问题
- 修复：网络受限环境下，授权校验反复失败导致的启动缓慢
- 修复：分流数据在国内网络环境下更新经常失败的问题
- 修复：退出应用后，下次启动的代理自动恢复状态偶发错乱

**优化**

- 授权校验自动选择并记住可用的网络通道，不再每次重复尝试已失败的路径
- 已激活的客户端在网络异常时启动，代理照常自动恢复
- 「清空日志」同时清空授权日志；网络异常时减少重复日志条目
- 弹窗按钮的禁用状态更清晰；若干文案修正
