# EchOS-Win v1.2.1

**授权体验完善。** 激活窗口交互与提示整批优化，稳定性修复若干。

**激活窗口**

- 激活按钮两态：蓝「激活」/ 绿「已激活」，失败原因显示在提示行，随时可重试
- 「激活」「重新校验」「检查网络」各自独立反馈，不再互相干扰
- 「检查网络」显示失败原因分类（连接超时 / 被拒绝 / 域名解析失败等）
- 限流、封禁等场景的提示更明确
- 「点我去 TG 群」按钮打开更快，且不再偶尔消失

**稳定性修复**

- 修复：与其他代理工具（如 v2rayN）同时使用时，停止代理后可能断网的问题
- 修复：网络异常时授权窗口的若干显示问题

**优化**

- 授权上报带平台标识，管理端可区分 Windows / macOS 客户端
- 授权日志的网络异常改为中文分类，更易排查
- 移除无引用的代码与资源
